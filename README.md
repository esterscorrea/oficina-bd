# Projeto Banco de Dados – Oficina Mecânica

## Descrição
Este projeto tem como objetivo a modelagem e implementação de um banco de dados relacional para o contexto de uma oficina mecânica, contemplando desde o esquema lógico até a persistência de dados e consultas SQL.

O projeto foi desenvolvido como parte do desafio de modelagem de banco de dados da DIO, utilizando o modelo relacional derivado de um diagrama entidade-relacionamento (ER).

---

## Estrutura do Banco de Dados
O banco de dados contempla as seguintes entidades principais:

- Cliente
- Veículo
- Ordem de Serviço
- Equipe
- Mecânico
- Serviço
- Peça

Os relacionamentos foram modelados respeitando integridade referencial, com uso de chaves primárias e estrangeiras.

---
